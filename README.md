# books-scraping

## About the project

`books-scraping` is a Python command-line application that collects the book
catalogue from [Books to Scrape](https://books.toscrape.com) and exports it to
`data/books.csv` in the project root. The report can be used for data analysis,
spreadsheet exploration, or web scraping practice.

The scraper discovers all categories, follows pagination within each category,
and extracts each book's category, full title, price, cover image URL, and rating.
It uses Requests for HTTP requests, Beautiful Soup for HTML parsing, and Python's
built-in `csv` module to write the report.

Each run starts collecting immediately, saves the CSV after all categories have
been processed, and exits. No scheduler, database, web server, API key, or
environment variables are required.

## Requirements

- Windows, macOS, or Linux with a terminal.
- Internet access to install tools and dependencies and reach Books to Scrape.
- Git to clone the repository, or a downloaded and extracted copy of the project.
- [uv](https://docs.astral.sh/uv/) to manage Python and project dependencies.
- Python 3.13 or later. The project's `.python-version` selects Python 3.13,
  which can be installed with uv as shown below.

## Installation and setup

### 1. Install uv

Use the command for your operating system from the
[official uv installation guide](https://docs.astral.sh/uv/getting-started/installation/).
Python does not need to be installed before using the standalone uv installer.

**Windows (PowerShell):**

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**macOS or Linux:**

```sh
curl -LsSf https://astral.sh/uv/install.sh | sh
```

After installation, restart your terminal so that the updated `PATH` is loaded,
then verify that uv is available:

```sh
uv --version
```

### 2. Get the project

Clone the repository and enter its root directory:

```sh
git clone https://github.com/carlosmichelutti/books-scraping.git
cd books-scraping
```

If you downloaded the project as a ZIP file, extract it and open a terminal in
the extracted directory containing `pyproject.toml` instead.

Run all remaining commands from the project root. They work in PowerShell,
macOS, and Linux terminals.

### 3. Install Python

Install the Python version selected by the project:

```sh
uv python install 3.13
```

uv can also use a compatible Python installation already on your machine. See
the [uv Python installation guide](https://docs.astral.sh/uv/guides/install-python/)
for details.

### 4. Install dependencies

```sh
uv sync --locked
```

This creates the `.venv` virtual environment and installs the dependencies
specified by `uv.lock`. The `--locked` option checks that the lockfile matches
`pyproject.toml` without updating it. You do not need to activate the virtual
environment manually when using `uv run`.

## Run the application

Start the scraper from the project root:

```sh
uv run --locked scripts/scraping_books.py
```

uv ensures the project environment is ready before running the script, so this
command can also install dependencies if you skipped the explicit sync step.
See the [uv project guide](https://docs.astral.sh/uv/guides/projects/) for more
about project environments.

The terminal shows progress for each category. After a successful run, it prints
the number of books saved, the absolute path to the CSV report, and the total
execution time. Open `data/books.csv` in a spreadsheet editor or use it in your
own analysis. Run the same command again whenever you want to refresh the report.

## CSV output

The report contains one row per collected book and the following columns:

| Column | Description |
| --- | --- |
| `category` | Book category name. |
| `title` | Full book title. |
| `price` | Numeric price in British pounds (GBP), without the currency symbol. |
| `image` | Absolute URL of the book's cover image; images are not downloaded. |
| `rating` | Star rating as text: `One`, `Two`, `Three`, `Four`, or `Five`. |

The `data` directory is created automatically. The CSV uses commas as separators
and UTF-8 with a byte order mark (BOM) to make it easier to open in Excel. Each
run overwrites the previous report after completing data collection.

## Troubleshooting

- **`uv` is not recognized or the command is not found:** restart your terminal
  after installation and check that uv's installation directory is on `PATH`.
- **Python cannot be found:** run `uv python install 3.13` and retry.
- **Requests fail:** check your internet connection and whether
  [Books to Scrape](https://books.toscrape.com) is accessible. Each page request
  has a 90-second timeout. Failed requests are retried up to three total attempts,
  with a 10-second delay between attempts; the scraper stops if all attempts fail.
- **Missing categories or invalid book data:** the site's HTML may have changed.
  The scraper raises an error when expected categories or book details are
  missing; its selectors may need to be updated.
- **The CSV cannot be written:** make sure the project directory is writable and
  close the report if it is open in an application that locks the file.
